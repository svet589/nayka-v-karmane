# Наука в кармане

Веб-демо образовательного приложения (химия + физика, 7–11 класс).

## Структура
- index.html — скелет страницы
- css/style.css — стили
- js/data.js — данные (элементы, формулы, реакции)
- js/scenes.js — 3D-движок на Canvas 2D
- js/chem.js — логика химии
- js/phys.js — логика физики
- js/app.js — точка входа, состояние, геймификация

Работает полностью офлайн после первой загрузки (все скрипты локальные).
